# widgetkit

Build widgets from Python or the shell.

- [Install & configure](#install--configure)
- [The my_var option](docs/guide.md#my_var-option)
- [Build and deploy](docs/guide.md#build--deploy)

## Install & configure

```bash
pip install widgetkit
widgetkit --run
```

## Usage

```python
from widgetkit import build_widget
```
